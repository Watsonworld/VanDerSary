# Codex 작업 지침

- `notes/원문-요구사항.md`와 `notes/요구사항.md`를 먼저 읽고, 실제 입력 Excel의 시트와 컬럼을 확인한 뒤 구현한다. 예시 컬럼을 실제 데이터로 가정하지 않는다.
- `input/article_list.xlsx`가 없으면 구조 분석 결과를 만들어내지 말고 파일을 요청한다.
- JCR 순위·JIF는 공식 Clarivate API 또는 사용자가 합법적으로 받은 `input/jcr/` Export에서만 확정한다. 출처, JCR 연도, 조회일을 기록한다.
- `notes/구현-체크리스트.md` 순서로 작업하고 각 단계의 실제 실행 결과를 기록한다.
- 매월 실행할 수 있도록 `main.py`를 만들되, 같은 JCR 연도에서 월별 순위가 바뀐 것으로 취급하지 않는다.
- 클라우드 작업에서는 기존 체크아웃을 사용한다. 사용자가 요청하지 않으면 Git worktree를 만들지 않는다.
