# JCR 자동화 작업 시작

1. [[원문-요구사항]]에서 전체 목표와 데이터 원칙을 확인한다.
2. [[요구사항]]에서 현재 합의된 요약을 관리한다.
3. [[구현-체크리스트]]의 순서대로 VS Code Codex에 작업을 맡긴다.
4. 실제 논문 Excel은 `input/article_list.xlsx`, 공식 JCR Export는 `input/jcr/`에 넣는다.
5. VS Code에서 `JCR: set up Python` 작업을 실행한다.

현재 원본 Excel과 JCR Export는 제공되지 않았다. 두 파일을 받은 뒤 실제 구조를 읽고 구현을 시작한다.
