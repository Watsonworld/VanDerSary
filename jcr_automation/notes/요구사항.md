# JCR 저널 목록 자동화

## 목표

교수별 논문 Excel에서 연구분야와 JCR Category를 추출하고, 최신 **공식 JCR 연도**의 저널 자료와 연결해 상위 3%, 3~7%, 7~10% 저널 목록을 매월 생성한다.

## 입력

- `input/article_list.xlsx`: 실제 시트와 컬럼을 확인한 뒤 매핑한다.
- `input/jcr/`: 기관에서 합법적으로 Export한 JCR CSV/XLSX. JCR 연도, Category, 저널명, ISSN/eISSN, JIF Rank, Category 전체 저널 수, JIF 등이 필요하다. 실제 헤더를 먼저 확인한다.

## 데이터 원칙

- 순위와 JIF는 추측하지 않는다. 공식 데이터가 없으면 `확인불가`로 표시한다.
- 저널 × JCR Category × JCR 연도를 기본 단위로 저장한다.
- 상위 비율 = JIF Rank / Category 전체 저널 수 × 100. 공식 JIF Percentile과 별도 열로 둔다.
- Category 이름이 애매하면 자동 확정하지 않고 검토 목록에 남긴다.
- 모든 값에 `source`, `retrieved_date`, `jcr_year`, `data_method`를 남긴다.

## 결과

`output/JCR_Target_Journals_YYYYMM.xlsx`에 교수별 연구분야, 세 상위 구간, 교수별 Target, Category Master, Category 통계, 전월 변경 내역, 출처, 교수별 시트를 만든다. 월별 순위 변경은 공식 JCR 데이터가 실제로 바뀐 경우에만 표시한다.

## 원문

상세 요구사항은 [[원문-요구사항]]을 따른다. 구현 전 실제 Excel 구조와 공식 JCR Export의 헤더를 이 문서에 추가한다.
