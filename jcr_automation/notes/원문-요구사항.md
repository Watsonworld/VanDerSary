POSTECH 산업경영공학과 교수별 연구분야와 JCR Category를 기반으로, 교수별·연구분야별 JCR 상위 저널 리스트를 자동 생성하는 Python 프로그램을 만들어줘.

## 1. 목표

첨부된 `article_list (15).xlsx`를 기반으로 교수별 연구주제 및 JCR Category를 추출하고, 각 JCR Category별 최신 JCR 정보를 확인하여 다음 세 구간의 저널 리스트를 자동 생성한다.

- JCR 상위 3% 이하
- JCR 상위 3% 초과 ~ 7% 이하
- JCR 상위 7% 초과 ~ 10% 이하

프로그램은 매월 반복 실행할 수 있도록 만들고, 이전 실행 결과와 비교하여 변경된 사항도 확인할 수 있어야 한다.

중요:
JCR은 기본적으로 연간 데이터이므로 “이번 달 JCR 순위”라는 표현을 그대로 가정하지 말고, 실행일 현재 사용 가능한 **가장 최신 JCR edition/year**을 확인하여 사용한다.
동일 JCR 연도 내에서는 순위가 매월 변경되는 것으로 간주하지 않는다.

# 3. 1단계: 교수별 연구분야 분석

`article_list (15).xlsx`에 포함된 논문 데이터를 분석하여 교수별 연구분야를 구성한다.

교수별로 다음 정보를 집계한다.

- 교수명
- 연구학문분야
- 주제키워드
- WOS Subject Categories
- WOS Categories
- IF(주제명)
- 해당 Category 출현 논문 수
- 전체 논문 중 Category 비율
- 최근 논문에서의 Category 출현 빈도

가능하면 최근 3~5년 논문에 더 높은 가중치를 부여한다.

예:

최근 1년 = weight 3
최근 2~3년 = weight 2
그 이전 = weight 1

교수별 JCR Category는 다음 세 단계로 분류한다.

1. 핵심 Category
2. 보조 Category
3. 참고 Category

Category 선정 근거를 데이터로 남긴다.

예:

교수명 | 연구주제 | JCR Category | 논문수 | 비율 | 가중점수 | Category구분

김병인 | OR/최적화 | Operations Research & Management Science | 12 | 38.7% | 28 | 핵심

# 5. 3단계: 최신 JCR 데이터 확보

가장 중요한 원칙:

JCR Rank, Journal Impact Factor, JIF Percentile, Category 전체 저널 수 등의 값은 가능한 한 **Clarivate의 공식 JCR 데이터**를 기준으로 한다.

데이터 소스 우선순위:

1. Clarivate 공식 API
2. 기관에서 합법적으로 접근 가능한 Clarivate/JCR 데이터
3. 사용자가 JCR에서 Export한 CSV/XLSX
4. 공개적으로 확인 가능한 공식 Clarivate 정보

Clarivate 로그인을 우회하거나 유료/기관인증 페이지를 무단 scraping하지 않는다.

웹 검색 결과나 일반 검색엔진의 숫자를 공식 JCR Rank처럼 사용하지 않는다.

공식 데이터를 자동으로 가져올 수 없는 경우 다음 폴더를 확인한다.

`./input/jcr/`

여기에 사용자가 JCR에서 Export한 CSV/XLSX 파일을 넣으면 자동으로 읽도록 한다.

예:

`JCR2025_Operations Research & Management Science.xlsx`

또는

`JCR_2025_AllCategories.xlsx`

# 6. 공식 JCR 접근 가능 여부 자동 판정

프로그램 시작 시 다음 순서로 확인한다.

1. 환경변수에 Clarivate API credential 존재 여부
2. JCR API 사용 가능 여부
3. `input/jcr/`에 최신 JCR Export 파일 존재 여부

환경변수 예:

CLARIVATE_API_KEY
CLARIVATE_API_SECRET

API가 실제로 제공하는 endpoint와 인증 방식은 반드시 공식 문서를 확인하고 구현한다.

존재하지 않는 API 또는 endpoint를 임의로 만들어내지 않는다.

API 사용이 불가능하다면:

`JCR 공식 데이터 자동 조회 불가 - JCR Export 파일 필요`

라는 메시지를 명확히 출력하고, 로컬 Export 파일 방식으로 진행한다.

# 8. JCR 상위 비율 계산

Category별 전체 저널 수와 JIF Rank를 기준으로 상위 비율을 계산한다.

기본 계산식:

Top_Percent = JIF_Rank / Total_Journals * 100

예:

Rank = 3
Total Journals = 109

Top Percent = 3 / 109 × 100
            = 2.7523%

따라서 `JCR 3% 이하`

구간 분류:

Top_Percent <= 3
→ `JCR 3% 이하`

3 < Top_Percent <= 7
→ `JCR 3% 초과~7% 이하`

7 < Top_Percent <= 10
→ `JCR 7% 초과~10% 이하`

Top_Percent > 10
→ `JCR 10% 초과`

계산값은 소수점 최소 4자리까지 내부적으로 유지한다.

표시할 때는 소수점 둘째 자리까지 표시한다.

---

# 9. JIF Percentile과 Rank%를 구분

Clarivate의 `JIF Percentile`과

`Rank / Total Journals × 100`

으로 계산한 상위 비율은 개념과 계산방식이 다를 수 있다.

따라서 두 값을 혼용하지 않는다.

Column을 별도로 만든다.

- JIF_Rank
- Total_Journals
- Rank_Top_Percent
- Official_JIF_Percentile
- JIF_Quartile

학과 내부의 3%, 7%, 10% 분류는 기본적으로:

`Rank_Top_Percent`

를 기준으로 한다.

공식 JCR 데이터에 별도의 Rank Percent 또는 학과평가 기준이 존재하면 설정파일에서 변경 가능하도록 만든다.

# 10. 복수 Category 저널 처리

Master key 예:

JCR_YEAR + ISSN + JCR_CATEGORY
